# LifeSaver 🩸

## Emergency Blood Donation & Coordination Platform

LifeSaver is a real-time blood emergency response platform that connects patients, individual donors, and organisation coordinators to make blood availability faster and more reliable during critical situations.

---

## Problem Statement

During medical emergencies, finding the right blood donor at the right time remains a major challenge due to disconnected donor networks, outdated information, and delays in communication.

LifeSaver aims to bridge this gap by creating a unified platform that enables quick coordination between patients, donors, and organisations.

---

## Solution

LifeSaver provides a digital emergency blood coordination system where:

- Patients can raise emergency blood requests.
- Individual donors can register and respond to requests.
- Organisations such as colleges, companies, trusts, and government groups can register coordinators who receive emergency requests.
- The platform enables faster communication during critical situations.

---

## Key Features

### User Management
- Secure user authentication using Firebase Authentication
- User profile management

### Blood Request System
- Create emergency blood requests
- Store patient and hospital details
- Track request status

### Donor Network
- Individual donor registration
- Organisation coordinator registration
- Blood group based matching

### Notification System
- Real-time request notifications
- Accept / Reject blood requests
- Donation completion tracking
